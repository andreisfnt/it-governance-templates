## Pre-Arrival (complete before start date)

### Identity and Access

- [ ] User account created in identity provider
- [ ] Account named per naming convention
- [ ] Role-based access groups assigned (minimum necessary permissions)
- [ ] Multi-factor authentication enforced on account
- [ ] Temporary credentials prepared for secure handoff
- [ ] **[Security]** Access scope reviewed and approved by manager

### Equipment

- [ ] Device selected and prepared per role profile
- [ ] Device enrolled in device management platform
- [ ] Required applications installed and licensed
- [ ] Encryption enabled and verified
- [ ] Device labeled and recorded in asset register (serial number, assigned user)
- [ ] Peripheral equipment prepared (if applicable): monitor, keyboard, headset, dock

### Communication and Collaboration

- [ ] Email account created
- [ ] Added to relevant team distribution lists and communication channels
- [ ] Calendar access configured
- [ ] Video conferencing access provisioned

### Network Access

- [ ] VPN or remote access provisioned (if applicable)
- [ ] Network access scope reviewed against role requirements
- [ ] **[Security]** Privileged access (if any) approved and documented

---

## Day 1

### Equipment Handoff

- [ ] Device handed over in person or shipped (tracking number recorded)
- [ ] Employee confirmed receipt
- [ ] Asset register updated with handoff date

### Account Activation

- [ ] Employee logged in successfully
- [ ] MFA setup confirmed
- [ ] Temporary password changed
- [ ] Email access confirmed
- [ ] Core applications accessible

### Security Briefing

- [ ] **[Security]** Acceptable use policy reviewed with employee
- [ ] **[Security]** Password policy explained
- [ ] **[Security]** Phishing and social engineering awareness covered
- [ ] **[Security]** Data handling and classification policy reviewed
- [ ] **[Security]** Incident reporting procedure explained (who to call, what counts as an incident)
- [ ] **[Security]** Employee acknowledged policies in writing

### IT Orientation

- [ ] IT helpdesk contact and process explained
- [ ] IT ticketing system access provided (if applicable)
- [ ] Known issues or limitations for the employee's setup communicated

---

## Week 1

- [ ] Employee confirmed all required systems are accessible
- [ ] Any access issues identified and resolved
- [ ] IT check-in completed (15 min) - any questions, issues, or missing access
- [ ] Shared drives and storage access verified
- [ ] Printing / scanning configured (if applicable)
- [ ] **[Security]** Security awareness training assigned and confirmed started

---

## Month 1

- [ ] Security awareness training completed and recorded
- [ ] Policy acknowledgment forms on file
- [ ] Any access requests since start date reviewed and approved correctly
- [ ] Device health check - encryption, updates, endpoint protection all current
- [ ] IT onboarding feedback collected from employee
